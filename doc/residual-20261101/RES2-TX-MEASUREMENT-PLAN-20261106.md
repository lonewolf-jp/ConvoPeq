# RES2-13 TX-02／TX-10 実機測定計画（2026-11-06）

- 本資料は 2026-11-06 の Owner 判断で、実機検証の測定計画・合否基準として採用された。実機測定の実施は別途承認を要する。


- 位置づけ: 実行承認ではない。実機検証を判断するための材料。
- 前提: 運用目標 1.0 ms、ハード制約 1.25 ms（48 kHz・512 サンプル）。実機・ASIO 検証の実施は未承認。

## 1. 測定環境（案）

| 項目 | 値 | 備考 |
|---|---|---|
| OS | Windows 11 x64 | 開発機 |
| ビルド | Release（icx 2026.2.0） | Debug は対象外 |
| オーディオ API | ASIO | デバイスは未確定（48 kHz 対応のもの） |
| サンプルレート | 48 kHz | 固定 |
| バッファ | 512 サンプル（1.25 ms） | ハード制約の基準と同じ |
| 入力 | 固定のテスト信号（正弦 1 kHz、-12 dBFS） | 実ファイルを固定 |
| IR | 固定の 1 本（長さ・SR を記録） | 差し替え用に別の 1 本を用意 |
| ウォームアップ | 最初の 8 ブロックを除外 | 計測区間から外す |
| 計測区間 | 各試行 60 秒 | 差し替え・更新の前後を含む |

## 2. 計測器

| 項目 | 取得方法 |
|---|---|
| ブロック処理時間 | `CONVOPEQ_RT_MEASURE=1`（Full）で `RtMeasureRing` に記録。`RtMeasureOverheadTests` と同じ経路 |
| XRUN | `XRunEvent`（`AudioEngine.h:1738`、`xRunBuffer`）を読み出して件数と時刻を記録 |
| publish 回数 | 公開カウンタ（`PublishPipelineIntegrationTests` と同じ系列） |
| 上書き・再試行 | `deferredOverwriteCount`、`recoveryRetryRedriveCount` |
| 再構築回数 | 既存の再構築カウンタ |
| 最終値 | 更新後のパラメータ値を取得し、最後の要求と比較 |

- XRUN の読み出し口は既存の診断経路を使う。実装上のアクセサ名は測定時に確認する。

## 3. シナリオ

### TX-02: IR 差し替え 1 回

1. 再生を開始し、60 秒の計測区間に入る。
2. 区間の 10 秒時点で IR を 1 回差し替える。
3. 区間終了まで継続し、計測値を回収する。

| 記録項目 | 期待 |
|---|---|
| publish 回数 | 1（差し替え 1 回につき 1） |
| superseded の publish | 0 |
| 旧 world の参照 | 差し替え後に 0 |
| deferredOverwrite / redrive | 0 / 0 |
| XRUN | 0 |

### TX-10: automation burst 100 件

1. 再生を開始し、60 秒の計測区間に入る。
2. 区間の 10 秒時点で、同一パラメータに 100 件の更新を投入する（最終値を固定）。
3. 区間終了まで継続し、計測値を回収する。

| 記録項目 | 期待 |
|---|---|
| 最終値 | 最後の更新と一致（完全一致） |
| 再構築回数 | 同一パラメータの連続更新なら 1。値が混在する場合は最終値の種類数以下 |
| superseded の publish | 0 |
| ブロック処理時間 | 下記の判定基準 |
| XRUN | 0 |

## 4. 試行回数と統計

- 各シナリオ 10 回。1 回ごとに新しいプロセスで開始する（状態を持ち越さない）。
- 各試行で次を記録する: 中央値、p95、最大値。全試行を通じた最大値も記録する。
- 外れ値の除外はしない。除外が必要なら理由を記録し、除外前後の両方を残す。
- 同一条件で再実行できるよう、IR・入力・パラメータ・ビルド・デバイス設定を固定して記録する。

## 5. 合否判定（案）

| 判定 | 条件 |
|---|---|
| 合格 | 全試行の最大ブロック時間が 1.0 ms 以下。XRUN 0。publish 回数・最終値・再構築回数が期待どおり |
| 条件付き | 最大が 1.0 ms 超 1.25 ms 以下。XRUN 0。他の項目は期待どおり。Owner の判断を要する |
| 不合格 | 最大が 1.25 ms を超える。または XRUN が 1 件以上。または最終値の不一致 |

- 1.0 ms は運用目標であり、達成の認定ではない。1.25 ms を超えた結果を自動的に waiver で許容しない。
- 判定は測定条件の記録とセットでのみ有効とする。条件が異なる結果を比較しない。
