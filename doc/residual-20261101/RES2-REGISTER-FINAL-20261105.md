## 22. 環境メモ（ビルド）

- icx ビルドは、この環境の oneAPI `setvars.bat` が `icx` を PATH へ追加せず、`libircmt.lib` も LIB に入らない場合がある。`compiler\latest\bin` を PATH、`compiler\latest\lib` と `mkl\latest\lib` を LIB に明示し、`MKLROOT` を設定すると通る（本セッションの再ビルドはこの手順）。
- `build.bat` は `setvars.bat` の後に `MKLROOT` を自前で設定する。CI（GitHub Actions）は MSVC と Clang を使うため、この影響を受けない。
