## 4. 原因帰属のために追加する測定項目（実装予定）

σ=158 µs の原因を切り分けるため、**既定 OFF の測定コードに限り**次を追加する。

| 項目 | 内容 | 出力例 |
|---|---|---|
| 横取りブロック数 | 目標周期を超えたブロックの数と割合 | `[U5ATTR] late_blocks=<n> late_ratio=<x>%` |
| 超過時間の分布 | 超過量の最大・p99・合計 | `[U5ATTR] overrun_max_us=<x> overrun_p99_us=<y> overrun_sum_us=<z>` |
| 原因区分 | 周期超過が「前ブロックの処理長」由来か「待機明け」由来かの別 | `[U5ATTR] cause=processing|wakeup|unknown` |
| 測定器オーバーヘッド | リング push と TSC 取得の所要（mode 1 と mode 2 の差から算出） | `[U5ATTR] instrument_us=<x>` |

- 実装は `#if CONVOPEQ_RT_MEASURE` 内に限定し、**RT 経路に新規確保・ロックを追加しない**
- 既定 OFF の挙動・性能は不変（`#if` で除去）

## 5. σ の再推定と判定
