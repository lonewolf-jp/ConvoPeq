## 2. elite 再評価の数理的評価

同一候補を 2 回評価して平均する場合、評価値が同一なら

```
Var((X + X) / 2) = Var(X)
```

であり、分散は減少しない。評価に独立ノイズが乗る場合のみ分散が半減する（`Var((X1+X2)/2)=σ²/2`）。現行は同一セグメントの再実行なので、**ばらつき低減の効果は無い**（ノイズ源がセグメント依存の場合）。

- 処理時間: 上位 3 候補 × 1 回の追加評価（母集団サイズに比例しない固定コスト）。
- 再現性: 決定性は維持される（乱数不使用）。
- 収束性: 平均化でスコアが変わらないため、選択順位への影響は原則なし（浮動小数の丸めを除く）。
