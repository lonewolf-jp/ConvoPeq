# BUG-058 — checkWorldConsistency: m_prevConfigDivergenceState_ を誤って流用

- **ファイル**: `src/audioengine/RuntimeHealthMonitor.cpp:937-949`
- **重大度**: MEDIUM
- **影響**: World Consistency Broken 検出時に Configuration Divergence の監視状態が上書きされ、Config Divergence が Warning/Error 中でも Normal に見える。逆に、Config Divergence が先行して Error の場合、World Consistency の初回検出が emitOnTransition でスキップされる。

## 概要

`checkWorldConsistency()` はワールド整合性の結果を `emitOnTransition()` に渡す際、**`m_prevConfigDivergenceState_`** を使用している。本来は専用の MonitorState フィールドを使うべきだが、`m_prevConfigDivergenceState_` を流用しており、Configuration Divergence 監視 (`checkConfigurationDivergence`) と World Consistency 監視が同一 state を共有している。

## コード位置

RuntimeHealthMonitor.cpp:937-949:
```cpp
void RuntimeHealthMonitor::checkWorldConsistency() noexcept
{
    if (!m_worldConsistencyCheck_)
        return;
    const auto consistencyState = m_worldConsistencyCheck_();
    // 0=Consistent, 1=Suspicious, 2=Broken
    if (consistencyState >= 2) {
        // Broken → Critical 相当の HealthEvent 発行
        emitOnTransition(m_prevConfigDivergenceState_, MonitorState::Error,  // ← 誤流用
            HealthEvent::Severity::Error, 5001,
            static_cast<uint64_t>(consistencyState));
    }
}
```

## 問題の詳細

### シナリオ1: Config Divergence の状態が上書きされる

1. `checkConfigurationDivergence()` が `m_prevConfigDivergenceState_` を `Warning` に設定
2. 同時に `checkWorldConsistency()` が Broken (>=2) を検出
3. `emitOnTransition(m_prevConfigDivergenceState_, Error, ...)` が呼ばれる
4. `m_prevConfigDivergenceState_` は `Warning → Error` に遷移
5. この Error の原因は World Consistency だが、Config Divergence 監視も Error と認識してしまう
6. 最悪、Config Divergence が Warning 状態だった原因が隠蔽される

### シナリオ2: World Consistency Broken の初回検出がスキップされる

1. `checkConfigurationDivergence()` が `m_prevConfigDivergenceState_` を `Error` に設定
2. `checkWorldConsistency()` が Broken を初検出
3. `emitOnTransition(m_prevConfigDivergenceState_, Error, ...)` → `current == new` で早期リターン
4. World Consistency Broken の HealthEvent が発行されない！

### クラス設計上の問題

`RuntimeHealthMonitor` は以下の専用 state フィールドを持つ:
- `m_prevConfigDivergenceState_` (Configuration Divergence 用)
- `m_prevSnapshotStarvationState_` (Snapshot Starvation 用)
- `m_prevStructuralDeployState_` (Structural Deployment 用)
- `m_prevProgressFreezeState_` (Progress Freeze 用)
- `m_prevSuppressionDurationState_` (Suppression 用)

World Consistency 用のフィールド (`m_prevWorldConsistencyState_` 等) が存在せず、`m_prevConfigDivergenceState_` が流用されている。

## 修正案

World Consistency 専用の MonitorState フィールド `m_prevWorldConsistencyState_` を追加し、`checkWorldConsistency()` で使用する。
