# BUG-057 — checkOverflowRate: eventCode に RETIRE_STALL を誤用

- **ファイル**: `src/audioengine/RuntimeHealthMonitor.cpp:763-847`
- **重大度**: LOW
- **影響**: Overflow rate の HealthEvent が retire stall のイベントコードで発行される。テレメトリ・ログ解析で誤認を招く。

## 概要

`checkOverflowRate()` 内で `emitOnTransition()` に渡す `eventCode` として `EVENT_RETIRE_STALL` (1001) と `EVENT_RETIRE_STALL_WARNING` (1002) が使用されている。これらの定数名は retire stall 用であり、overflow rate 監視に使用するのは誤り。

## コード位置

RuntimeHealthMonitor.cpp:796-801:
```cpp
emitOnTransition(m_prevOverflowRateState, desiredState,
    desiredState == MonitorState::Error
        ? HealthEvent::Severity::Error : HealthEvent::Severity::Warning,
    desiredState == MonitorState::Error ? EVENT_RETIRE_STALL : EVENT_RETIRE_STALL_WARNING,
    ratePerSec);
```

同様の誤用が下降方向ヒステリシス (line 820-824):
```cpp
emitOnTransition(m_prevOverflowRateState, desiredState,
    HealthEvent::Severity::Info,
    EVENT_RETIRE_STALL_WARNING,
    ratePerSec);
```

安定維持中の Normal 遷移 (line 840-843):
```cpp
emitOnTransition(m_prevOverflowRateState, MonitorState::Normal,
    HealthEvent::Severity::Info,
    EVENT_RETIRE_STALL_WARNING,
    ratePerSec);
```

## 問題の詳細

`RuntimeHealthMonitor.h` で定義済みの event code:

| 定数 | 値 | 意図された用途 |
|------|-----|--------------|
| `EVENT_RETIRE_STALL` | 1001 | Retire backlog stall |
| `EVENT_RETIRE_STALL_WARNING` | 1002 | Retire backlog warning |
| `EVENT_READER_STUCK` | 3001 | Reader stuck |
| `EVENT_CROSSFADE_TIMEOUT` | 4001 | Crossfade timeout |
| `EVENT_CROSSFADE_EVENT_DROP` | 4002 | Crossfade drop |

Overflow rate 専用の event code は定義されていない。コピーペーストの修正漏れと考えられる。

### 影響

- テレメトリダッシュボードで overflow rate の警告が retire stall として分類される
- 障害解析時に「overflow rate が高いのに EVENT_RETIRE_STALL しか出ていない」と誤認
- 根本原因の切り分けに不要な時間がかかる

## 修正案

Overflow rate 専用の event code を追加:

```cpp
// RuntimeHealthMonitor.h
static constexpr uint32_t EVENT_OVERFLOW_RATE_WARNING = 1012;
static constexpr uint32_t EVENT_OVERFLOW_RATE_CRITICAL = 1013;
```

`checkOverflowRate()` 内の eventCode を上記に置き換え。
