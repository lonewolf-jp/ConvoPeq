# 残存課題レジスタ（分類と追跡）

- 分類基準: `main` = `f641a187`（外部監査 13 件と N1 の判定時点）
- 現在の `main`: `f7dcdf7a`（`ConvoPeq.md` の更新のみ。ソース変更なし）
- 目的: 監査 13 件と N1 を「未修正バグ／非バグ既知課題／解消済み／コード外残課題」に分類し、ID ごとに状態・影響・判断・承認範囲・残作業を追跡できるようにする。

## 1. 分類の定義

| 分類 | 定義 |
|---|---|
| 未修正バグ | コードの欠陥であり、修正が必要と判断されたもの |
| 非バグ既知課題 | 仕様・性能・文書・堅牢化に関わるが、バグではないと確定したもの |
| 解消済み | 修正のマージ、または非バグ確定でクローズしたもの |
| コード外残課題 | 実機、実行環境、文書生成など、コード変更以外のもの |
