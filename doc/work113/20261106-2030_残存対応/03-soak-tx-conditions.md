### 1.3 合否基準（案）

次のすべてを満たす場合に PASS とする。

1. 終了コードが 0。
2. 出力に `ALL PASS` がある。
3. `rejected=0`、`peakBacklog=0`。
4. s5 のメモリが `converged`（最終値がピークと同じ）。
5. ASan ビルドで実行した場合、ASan の報告がない。

失敗した場合は、失敗したシナリオだけを再実行し、再現の有無を記録する。再現した場合は、変更 commit と実行ファイルのハッシュを添えて報告する。

### 1.4 実行手順（案）

```
cmake --build build --config Release --target AudioEngineHarness
build\Release\AudioEngineHarness.exe --soak --scenario=all
```

- 実行前に他の負荷（ビルド、WSL、計測ツール）を止める。
- 実行ファイルの SHA-256、ビルド日時、commit を記録する。
- ログは標準出力と標準エラーをまとめて 1 ファイルに保存する。
