## 4. バイパス解除後の wet 絶対レベル一致の位置づけ

### 4.1 既存設計と PR #168 の関係

`processBypassWithLatencyCompensation` は、遅延補償したドライ信号をリングバッファから出力し、wet の畳み込みを実行しない。PR #168 はこの関数自体を変更せず、**呼び出し条件だけ**を変えた。ミックスが dry に収束した後でなければバイパス経路へ dispatch しない、という条件である。

| 項目 | PR #168 の変更 |
|---|---|
| `Runtime.cpp` | バイパス dispatch に「ミックスが 0 へ収束し、smoother が停止している」条件を追加。状態変化時に専用 20 ms のランプをやり直し、収束後に `smoothingTimeSec` へ戻す（+40 / −2 行） |
| `ConvolverProcessor.h` | 定数 1 個と bool 2 個、テストシームの friend（+6 行） |
| `ConvolverProcessor.Lifecycle.cpp` | `prepareToPlay` でフェード状態を初期化（+5 行） |
| `processBypassWithLatencyCompensation` | **変更なし** |

したがって、バイパス定常では wet の状態が凍結され、解除時に凍結点から再開する。Issue #158 の背景に書かれた挙動と一致する。

### 4.2 要求・仕様としての有無

| 資料 | 記述 | 判定 |
|---|---|---|
| Issue #158 | 3 つの要望。絶対レベル一致を求める記述はない。「凍結され、解除時に凍結点から再開する」を背景として記載 | 要求なし |
| `SOUND_PROCESSING.md` | `mix`（dry/wet）と `bypassed` を atomic パラメータとして列挙。遷移時のレベル契約の記述はない。EQ のバイパスには 5 ms のクロスフェード定義があるが、Convolver のバイパスは対象外 | 要求なし |
| `ARCHITECTURE.md` §9 | 「Convolver bypass toggle / `m_irFadeTimeSec`（80 ms）」と記載。しかし同節の `CrossfadeAuthority` は `dspProjection` の `irLoaded` / `structuralHash` / `oversamplingFactor` だけで判定し、バイパスは入力にない | 記述はあるが実装と一致しない（文書の不整合） |
| 実装テスト | 境界の段差とフェード長を検証する。絶対レベル一致は検証しない | 要求なし |

**要求としては存在しない。** 存在するのは「凍結点から再開する」という仕様であり、「連続処理した参照との一致」はそこから要求される性質ではない。§4.3 の不一致は、この凍結セマンティクスの帰結である。

### 4.4 必要性

「連続処理した参照との一致」は、バイパス中も wet を処理し続ける方式（要望 2 のテール保持）を採用したときに初めて意味を持つ受入基準である。現行の凍結セマンティクスでは、参照と一致しないのが正しい。

したがって次の 3 点を整理できる。

- 現時点の要求ではない。
- N1 の回帰でもない（修正前から不一致）。
- 導入するなら「テール保持」という別機能の受入基準になる。

### 4.5 検証可能性

既存の WAV と短い解析で測れる（§4.3 が実演）。恒久的に扱う場合は、`--n1-analysis` に「OFF 後の窓と参照の比」を出す項目を追加するのが自然である。ctest には登録せず、54 / 54 を維持できる。

## 5. 別 PR 起票の要否

**現時点では起票しないことを推奨する。** 要求が存在せず、N1 の回帰でもなく、実装するなら別機能（テール保持）になるためである。起票すると、N1 の受入と混在させる危険がある。

Owner がテール保持を望む場合の提案骨子は次のとおり。起票はしていない。

| 項目 | 内容 |
|---|---|
| 課題の定義 | バイパス中も wet の畳み込みを継続し、解除後にテールが自然に続くようにする。受入は「解除後の所定窓で、連続処理した参照との比が仕様値以内」 |

| 必要な受入基準 | 境界は既存 T1（切替前テールの 25%）。テール保持は「参照との比」を新設する。閾値は仕様判断であり、現時点で決めない |

| 別 PR とする合理性 | 要求・受入基準・検証が独立している。N1 の受入済み判定を動かさずに検討できる |
