===== .github/scripts/isr-verify-proof-scope.ps1:404  (in_reply_to=-)


** Minor** · **Functional Correctness** · **Quick win**

**Accept only top-level Release guards in the proof-scope check.**

`Get-ConditionalReturns` matches `if (cond) { return; }` at any brace depth. A guard nested in a block that does not always run still counts. Example: `if (false) { if (mode == "Release") { return; } }`. Both position checks pass when the trace call follows that block, so Release can emit the HB trace.

The same gap applies to the `emitHBTrace()` suppression check.

Count a guard only when it is a top-level statement of the function body. Add a fixture with a nested Release guard that must fail the check.
